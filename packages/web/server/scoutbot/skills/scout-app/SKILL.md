# Scout app and protocol

Use `scoutbot_guide` when the operator asks how Scout works, what a screen or setting means, or how its runtime and protocol route work. Pick the narrowest topic. The tool reads the maintained repository docs only when called; follow their links with `read` if the answer needs more detail.

Treat docs as design and implementation guidance. For a question about what is happening **now**, check live records with Scout read tools. For a claim about behavior that may have changed, inspect the relevant source before answering. Give the operator the short answer and name the source you used. Do not claim that a documented feature is running or installed solely because it appears in a doc.
